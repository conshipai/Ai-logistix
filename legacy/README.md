# Legacy AI Logistix static site

These files are the original single-page AI Logistix corporate website that lived at the
repository root before MConnect was introduced. They are preserved here unchanged so the
static deployment can continue to be served if needed.

To run it locally:

```bash
docker compose -f legacy/docker-compose.yml up
```

The MConnect application (Next.js) now lives at the repository root. See `../README.md`.
